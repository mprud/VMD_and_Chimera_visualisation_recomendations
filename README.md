## Про посібник

Посібник розрахований на студентів та молодих науковців хіміко-біологічного профілю, які прагнуть опанувати візуалізацію молекулярних структур за допомогою <strong>VMD</strong> та <strong>Chimera</strong>.

У цьому репозиторії зібрані файли та матеріали для лабораторних робіт. Для зручності вони розподілені за програмами:

| Програма | Матеріали |
|:--|:--|
| <strong>VMD</strong> | [Перейти до лабораторних робіт](./VMD/) |
| <strong>Chimera</strong> | [Перейти до лабораторних робіт](./Chimera/) |

## Структура репозиторію

```text
├── VMD/       Матеріали лабораторних робіт у VMD
└── Chimera/   Матеріали лабораторних робіт у Chimera
```

У папці кожної програми матеріали можна впорядковувати за окремими лабораторними роботами — наприклад, <code>ЛР1</code>, <code>ЛР2</code> тощо.
