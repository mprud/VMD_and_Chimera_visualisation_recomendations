## Про посібник

Посібник розрахований на студентів та молодих науковців хіміко-біологічного профілю, які прагнуть опанувати візуалізацію молекулярних структур за допомогою **VMD** та **Chimera**.

У цьому репозиторії зібрані файли та матеріали для лабораторних робіт. Для зручності вони розподілені за програмами:

| Програма | Матеріали |
|:--|:--|
| **VMD** | [Перейти до лабораторних робіт](./VMD/) |
| **Chimera** | [Перейти до лабораторних робіт](./Chimera/) |

## Структура репозиторію

```text
├── VMD/       Матеріали лабораторних робіт у VMD
└── Chimera/   Матеріали лабораторних робіт у Chimera
```

У папці кожної програми матеріали можна впорядковувати за окремими лабораторними роботами — наприклад, `ЛР1`, `ЛР2` тощо.
