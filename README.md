## Про посібник

Посібник розрахований на студентів та молодих науковців хіміко-біологічного профілю, які прагнуть опанувати методи візуалізації молекулярних структур у популярних програмних середовищах VMD та Chimera. У ньому подано основні принципи роботи з файлами PDB, молекулярними структурами та графічним оформленням результатів.

У цьому репозиторії зібрані файли та матеріали для лабораторних робіт. Для зручності вони розподілені за окремими папками для кожної програми.

| Програма | Матеріали |
|:--|:--|
| <strong>VMD</strong> | [Перейти до лабораторних робіт](./VMD/) |
| <strong>Chimera</strong> | [Перейти до лабораторних робіт](./Chimera/) |

## Структура репозиторію

```text
├── VMD/       Матеріали лабораторних робіт у VMD
└── Chimera/   Матеріали лабораторних робіт у Chimera
```

У папці кожної програми матеріали можна впорядковувати за окремими лабораторними роботами — наприклад, `ЛР1/`, `ЛР2/` тощо.
