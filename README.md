Посібник розрахований на студентів та молодих науковців хіміко-біологічного профілю, які прагнуть перетворити сухі масиви координат на наочні 3D-моделі для своїх навчальних та дисертаційних робіт. Також він стане прикладним інструментом для викладачів та експериментаторів, яким необхідна якісна наукова графіка для публікацій у провідних міжнародних журналах.
